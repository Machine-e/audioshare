# MiSans

Official, unmodified MiSans Regular / Medium / Semibold OpenType fonts, mapped
to the application's body (400), controls (500), and heading (600) styles.

Source: https://hyperos.mi.com/font/
Archive: https://hyperos.mi.com/font-download/MiSans.zip
